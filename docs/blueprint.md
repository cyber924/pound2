# **App Name**: Pound Hub

## Core Features:

- 서비스 포트폴리오 표시: 카드 기반 레이아웃으로 Pound의 서비스를 보여주고, 각 서비스는 상세 보기로 연결됩니다.
- 서비스 연결: 동적 라우팅을 사용하여 서비스 데모 또는 사이트로 직접 이동할 수 있습니다.
- AI 기반 서비스 등록: AI 도구를 사용하여 등록 시 서비스 세부 정보(이름, 설명, 썸네일, 기술 스택)를 자동으로 생성합니다.
- 통합 계정 시스템: Supabase Auth 및 JWT Federation을 사용하여 모든 서비스에서 단일 Sign-On 시스템을 구현합니다.
- 서비스 수준 인증: 통합 계정(이메일, 이름)에서 동기화될 가능성이 있는 개별 서비스 가입 흐름을 지원합니다.
- 검색 및 필터링: 사용자가 이름, 카테고리 및 기술 스택별로 서비스를 검색하고 필터링할 수 있습니다.
- 테마 UI: 사용자 정의 가능한 다크/라이트 모드 및 브랜드 색상 테마를 제공합니다.

## Style Guidelines:

- 기본 색상: 브랜드 아이덴티티를 유지하고 신뢰를 불러일으키기 위해 Pound Navy(#2D2B55)를 사용합니다. 다크 또는 라이트 UI에서 잘 작동하는 채도가 높고 다재다능한 색상입니다.
- 배경 색상: 깨끗한 배경을 위해 Pound Navy(#E8E8ED)의 채도가 낮은 밝은 변형을 사용합니다.
- 강조 색상: 기본 색상을 보완하고 시각적 흥미를 제공하며 주요 요소를 강조하는 골드 톤(#F7C948)입니다.
- 본문 및 제목 글꼴: 현대적이고 중립적인 느낌을 위해 제목과 본문 텍스트 모두에 적합한 'Inter'를 사용합니다.
- 모션 기반 전환으로 향상된 서비스 목록에 카드 기반 레이아웃을 사용합니다.
- 사용자 경험을 향상시키기 위해 미묘한 호버 애니메이션과 매력적인 AI 등록 모션을 사용합니다.
